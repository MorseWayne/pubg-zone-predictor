# 地图半沉浸式 UI 与坐标清除设计

日期：2026-06-06

## 背景

当前地图工作台已改为 Canvas 渲染，并支持 Miramar high-res、拖拽、缩放、重置和单击标点。用户继续提出两个 UI 优化目标：

1. 地图可视化区域需要更大，减少当前地图区域内和页面布局上的留白。
2. 当前圈中心和战队位置不仅要能设置，也要能分别取消。

已确认的设计方向：

- 采用半沉浸式右侧浮层布局。
- 控制面板浮在地图右侧，而不是占据固定右侧网格列。
- 当前圈中心和战队位置在坐标卡片中分别提供“清除”按钮。

## 目标

- 地图成为页面主体，Canvas 可视区域显著变大。
- 保留现有地图 toolbar、点击模式、缩放 HUD 和预测工作流。
- 控制面板仍随时可见，并能在高度不足时滚动。
- 用户可以分别清除当前圈中心和战队位置。
- 清除坐标后旧预测结果不再展示，避免与输入状态不一致。

## 非目标

本次不做：

- 完整控制面板抽屉收起/展开动画。
- Canvas marker 上的可点击删除按钮。
- 右键清除 marker。
- 移动端触摸交互优化。
- 重新设计预测结果展示结构。

## 布局设计

`workspace-grid` 改为一个相对定位的地图工作区，不再使用固定 `1fr + 390px` 的两栏布局。

地图区域：

- 地图卡片占据工作区主体宽度。
- 高度尽量接近视口剩余高度，例如 `calc(100vh - header - page padding - gap)`。
- `.map-frame` 内边距/外边距从当前较大的 `20px` 降到约 `8px–12px`。
- Canvas 继续填满 `.map-frame`。
- 地图 toolbar 保留，但压缩高度，只显示地图名、资源状态和点击模式按钮。

控制面板：

- 从右侧固定列改为地图上的右侧浮层。
- 宽度约 `360px`。
- 距离地图边缘约 `12px–16px`。
- 使用半透明深色背景、边框和 blur，保证地图上下文仍可见。
- 设置 `max-height`，内容超出时面板内部滚动。
- 保留现有控制内容：状态、数据准备、地图选择、Zone、路线策略、坐标、LLM、生成预测、预测结果。

## 坐标设置与取消设计

保留当前设置方式：

- toolbar 中继续使用两个模式按钮：
  - 设置当前圈中心
  - 设置战队位置
- 在地图上单击后按当前模式设置对应坐标。
- 设置当前圈中心后，自动切换到“设置战队位置”。

新增取消方式：

- 坐标区域改为两个可操作卡片：
  - 当前圈中心卡片
  - 战队位置卡片
- 每张卡片显示：
  - label
  - 坐标值或“未设置”
  - 已设置时显示“清除”按钮

清除当前圈中心时：

- `currentCircleCenter = null`
- `prediction = null`
- `predictError = null`
- 预测按钮不可用
- 点击模式切回 `current_circle_center`
- 保留地图当前 pan / zoom，不重置视图

清除战队位置时：

- `teamArea = null`
- `prediction = null`
- `predictError = null`
- 预测按钮不可用
- 点击模式切到 `team_area`
- 保留地图当前 pan / zoom，不重置视图

切换地图时：

- 必须同时清空 `currentCircleCenter`、`teamArea` 和 `prediction`，避免 Erangel/Miramar 坐标语义混用。
- 必须清空 `predictError`，并将 `predictState` 重置为 `idle`。
- 点击模式回到 `current_circle_center`。
- 现有热点和训练结果仍按当前地图重新加载或重置。

切换 Zone 时：

- 保留已设置坐标。
- 清空旧预测和错误，因为当前圈半径改变后旧预测结果不再完全可信。
- 将 `predictState` 重置为 `idle`。

异步预测一致性：

- 清除任一坐标、切换地图或切换 Zone 时，如果 `/api/predict` 请求正在进行，必须中止请求或通过请求序号/token 丢弃过期响应。
- 过期预测响应不得重新写回 `prediction`、`predictState` 或 `predictError`。
- 清除坐标后 `predictState` 应重置为 `idle`，预测按钮因输入不完整保持 disabled。

## 组件与数据流

主要改动集中在：

- `frontend/src/App.tsx`
  - 新增清除当前圈中心和清除战队位置的 handler。
  - 将坐标读数组件改为带清除按钮的可操作组件。
  - 切换地图时清空坐标和预测。
  - 切换 Zone 时清空预测和错误。
- `frontend/src/styles.css`
  - 调整 `.workspace-grid`、`.map-card`、`.map-frame` 为半沉浸式布局。
  - 将 `.control-panel` 定位为地图右侧浮层。
  - 为坐标卡片和清除按钮添加样式。

`InteractiveMapCanvas` 不需要新增删除 marker 的 hit-testing。它继续只负责渲染和将单击转换为 world 坐标。

## 错误处理

- 地图资源不可用时，地图 blocker 继续覆盖 Canvas。
- 控制面板浮层仍显示配置、Zone 和资源状态。
- 清除任一坐标时，旧预测结果和预测错误必须清除，`predictState` 必须重置为 `idle`。
- 清除、切换地图或切换 Zone 后，任何较早发起的预测响应都必须被忽略或取消。
- 清除坐标不影响地图资源、热点准备状态、模型训练状态，也不重置地图视图。
- 如果清除后用户直接点击“生成预测”，按钮应处于 disabled，不发出请求。

## 验证计划

自动验证：

- `npm run build:frontend`
- 如实现触及后端或共享配置，再运行相关后端测试。

手动验证：

- 地图可视区域比当前版本明显更大。
- 地图卡片内部无大块无意义留白。
- 控制面板浮在右侧，内容过长时可滚动。
- 地图拖拽、滚轮缩放和重置仍可用。
- 当前圈中心和战队位置仍能通过地图单击设置。
- 坐标卡片显示对应坐标。
- 清除当前圈中心后，圈心 marker 消失，预测结果清空，点击模式回到设置当前圈中心。
- 清除战队位置后，队伍 marker 消失，预测结果清空，点击模式切到设置战队位置。
- 清除任一坐标后，地图 pan / zoom 状态不重置。
- 切换地图后坐标和预测清空。
- 切换 Zone 后坐标保留，但预测结果清空。

## 风险与缓解

- **浮层遮挡地图。** 缓解：浮层宽度控制在约 `360px`，地图仍可拖拽/缩放查看被遮挡区域。
- **控制面板内容较长。** 缓解：设置 `max-height` 和内部滚动。
- **清除坐标后旧预测残留。** 缓解：清除 handler 同步清空 `prediction` 和 `predictError`。
- **布局高度在不同屏幕上异常。** 缓解：使用 `min-height` 和 `calc(100vh - ...)` 组合，保证小屏仍可滚动。
